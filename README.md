# Arkham Horror Card Game Token Dealer
## version 1.0

[Arkham Horror Token Dealer can be found here](https://crabinak.github.io/ahcg-token-dealer/)

This is a tool created for the Arkham Horror Card Game. It is designed to work well on a phone, since this would be the most likely usage. 

The current system in the Arkham Horror Card Game calls for drawing random tokens from a bag to decide skill tests. This tool automates the process so you no longer need to sort tokens, put them in a bag, and shake the bag around (hoping the Doom tokens don't just sit on top the whole time) before drawing tokens. Hopefully this speeds things up a bit.

The user can add tokens to the "bag" by choosing "Add Tokens" and selecting which tokens and how many to add. Clicking added tokens will remove them from the bag. Choose "Done" when finished to return to the main screen.

The user can choose "Draw Token" to draw a random token from their chosen pool. There is also the option to set the number of tokens drawn at a time, in case that is needed (you won't pull duplicates unless duplicates exist in the bag. This is equal to pulling three tokens from the bag, not randomly drawing from the entire pool three times).
